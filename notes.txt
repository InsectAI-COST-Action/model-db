Framework: Hugo (https://gohugo.io/, htmx/html and Go)

It derives what to do from the folder naming conventions, it reads a hugo.toml and in that root folder it starts searching for those.

content/ : contains the pages of the website (index, about, contributing etc...)

data/ : global data loaded once, toml schemas in our case, to validate cards and define how the homepage is structured

layouts/ : HTML templates for the website

assets/ static/ and public/ (build of the site)

Then, for what regards the rendering of the model card, inside models we have some "partial" calls to "validate.html" that validates it using the schema.toml, and then it renders ".Content" that is the markdown for each model card.

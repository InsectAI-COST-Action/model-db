# This folder moved

Format descriptors that used to live under `static/formats/detection/*.json`
were flattened into `static/formats/*.json` in PR #62 (2026-09-30). If your
code, notebook or bookmark points at `static/formats/detection/<file>.json`,
update it to `static/formats/<file>.json` — see
[static/formats/README.md](../README.md) for the current catalog.
